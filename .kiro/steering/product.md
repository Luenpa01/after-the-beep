# Product: After the Beep

After the Beep resurrects the 1980s answering machine as a shield against phone scams targeting older adults. It answers every unknown call first, verifies anyone claiming to be family with a safe word, and blocks scams before the phone ever rings.

- Protected person: older adult, referred to as "Grandma Gloria".
- Caregiver: sets up the system, receives alerts, corrects verdicts, referred to as "Camila".
- Hackathon judge: must be able to try it from the browser.

Non-negotiable principles:
1. When in doubt, save the message; never block a verified family member.
2. The safe word is never written to logs, transcripts, prompts, or alerts.
3. Every alert ends with one concrete action for the family.
4. Deterministic rules always decide; the language model only adds signals.

Languages: English and Spanish, both for the voice agent and the interfaces.
